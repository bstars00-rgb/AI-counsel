# 01 · 서비스 개요

## 1.1 서비스 한 줄 정의

> OHMYHOTEL & CO 트래블쇼 부스 방문 고객이 **이름 / 생년월일 / 태어난 시(12 시진)** 를 입력하면,
> AI 마스코트 "오마이치"가 **사주를 가볍게 풀이**하고 **오늘 어울리는 여행지 + 오마이호텔 추천 호텔 Top 3**를 골라주는
> 마케팅 미니 웹앱.

## 1.2 목적

- **부스 방문객의 이목 끌기** — 운세 콘텐츠로 자연스러운 진입 후크
- **오마이호텔 브랜드 노출** — 일본/한국/베트남 Top 100 호텔 리스트를 운세 결과에 자연 노출
- **SNS 공유성** — 사주 키워드 + 도시 매치 카드를 인스타용 캡처 비주얼로
- **단순 / 빠름** — 입력 ~30초, 결과 즉시. 부스 동선에서 30~60초 내 완결

## 1.3 비목표 (의도적으로 미포함)

| 영역 | 미포함 |
|---|---|
| 거래 | 실시간 예약 / 결제 / 견적 발송 |
| 외부 연동 | 호텔/항공 API / 외부 검색엔진 / 결제 PG |
| 고객 데이터 | 회원가입 / 로그인 / 입력값 저장 / CRM / 마케팅 자동화 |
| 정통 명리학 | 천간/지지/오행을 **분위기 한 마디**로만 활용. 정확한 만세력/대운 계산 X |
| 관리/대시보드 | 관리자 페이지, 통계, KPI |
| 멀티턴 대화 | 1회 입력 → 1회 결과 |
| 다국어 | 한국어 단일 |

## 1.4 사용자 시나리오 (대표 페르소나)

**페르소나 A — 30대 직장인 여성, 부스 앞 행인**
- 상황: 트래블쇼 부스 옆 지나가다 "오늘의 사주 여행지" 글자에 멈춤
- 행동: 태블릿에서 이름 + 생년월일 + 태어난 시 선택 → 30초 뒤 "오늘 당신은 도쿄 / 푸드 & 야경" 결과 확인
- 가치: 재미있는 인스타 캡처거리 + 도쿄 호텔 3곳 알게 됨

**페르소나 B — 40대 부부, 신혼여행 / 가족여행 검색 중**
- 상황: 부스 직원이 "운세 보세요" 권유
- 행동: 둘 다 입력해보고 추천 도시 비교, 호텔 카드 보고 부스 직원에게 추가 문의 (수동)
- 가치: 부스 직원과 자연스러운 대화 출발점

## 1.5 핵심 가치

| 가치 | 어떻게 |
|---|---|
| **이목** | "사주로 보는 여행지"라는 후크 + 오마이치 캐릭터 친근감 |
| **빠름** | 입력 3개 → 결과 1화면. 0.7~1.2초 로딩 |
| **재미** | 사주 키워드 칩(#불의 기운, #부드러운 휴식), 도시 매치 점수 |
| **신뢰감** | 오마이호텔 Top 100 호텔 실제 데이터 자연 노출 |

## 1.6 기술 스택

| 영역 | 선택 |
|---|---|
| 정적 단일 페이지 (부스 메인) | `index.html` + Tailwind CDN + Vanilla JS |
| 풀스택 (선택, Claude API 연동시) | Next.js 14 (App Router) + React 18 + TypeScript |
| 스타일 | Tailwind CSS |
| AI | Anthropic Claude API (모델: `claude-opus-4-7` 기본, env 로 변경 가능) |
| 구조화 출력 | Claude `output_config.format = json_schema` (스키마 강제) |
| 호스팅 (P0) | GitHub Pages — Mock 데이터 |
| 호스팅 (P1) | Vercel / Render — Next.js + Claude API |
| 원본 호텔 데이터 | xlsx → 빌드 시 TypeScript 객체로 변환 (`lib/hotels.ts`) |

## 1.8 보안 / 개인정보

- **저장 없음** — 입력값(이름·생년월일·시)은 메모리에만, 결과 화면 종료 시 휘발
- **로컬스토리지 미사용** (이전 버전 제거됨)
- **외부 전송** — Claude API 사용 시 입력값이 Anthropic 서버에 전달됨 (footer 안내 권장)
- **API 키 비노출** — `index.html` (GitHub Pages) 은 Mock 모드 전용, 키 미포함. Next.js 만 서버 측에서 키 사용
