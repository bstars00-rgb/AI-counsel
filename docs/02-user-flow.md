# 02 · 사용자 흐름 + 화면 명세

## 2.1 전체 흐름

```
┌──────────┐    제출    ┌──────────┐  0.7~1.2s   ┌──────────┐
│  입력    │ ─────────▶ │  로딩   │ ─────────▶ │  결과   │
│ (view=   │            │ (view=   │            │ (view=   │
│  input)  │            │  loading)│            │  result) │
└──────────┘            └──────────┘            └─────┬────┘
                                                       │
                                          ┌────────────┼────────────┐
                                          │            │            │
                                   "다른 사주로     "처음으로"   (스크롤만)
                                    다시 보기"
                                          │            │
                                          ▼            ▼
                                     [입력 화면]   [입력 화면 + 폼 초기화]
```

세 가지 view 만 존재: `input` / `loading` / `result`. 라우팅 없이 단일 SPA. 새로고침 시 항상 `input` 으로 시작.


### 2.4.2 입력 필드

| 필드 | 컴포넌트 | validation |
|---|---|---|
| 이름 | `<input type="text" maxlength="40">` | 1~40자 비공백 |
| 생년월일 | `<input type="date" min="1900-01-01" max="오늘">` | YYYY-MM-DD, 1900 ~ 오늘 |
| 태어난 시 | 13개 버튼 grid (sm:grid-cols-4) | 12 시진 + "모름". 기본값 = "모름" |

### 2.4.3 인터랙션

- **이름 input** — Enter 키 + 유효 입력이면 즉시 제출
- **태어난 시 버튼** — 클릭 시 즉시 선택 (`state.input.birthtime` 변경)
- **선택된 버튼** — `border-brand-500 bg-brand-50 text-brand-700` 표시
- **제출 버튼** — `이름 && 생년월일` 둘 다 입력되어야 활성. disabled 상태 = `bg-slate-300`
- **에러 메시지** — 카드 내 상단 빨간 박스 (`bg-red-50 text-red-700`)

### 2.4.4 키보드 단축

| 키 | 동작 |
|---|---|
| Enter (이름 input) | 폼 제출 (유효시) |

## 2.6 view = `result` (결과 화면)

### 2.6.1 전체 구조

순서대로 세로 배치 (`space-y-4`):

```
1) 헤드라인 카드  (오렌지 그라데이션, 대형 H2 + 별점 + 키워드 칩 + 본문)
2) 카테고리 4분할 (sm:grid-cols-4) — 여행운/재물운/인연운/건강운
3) 추천 여행지 카드 (오렌지 그라데이션, 도시명 H3 + 매치 점수 + 사주 reason + dl)
4) 추천 호텔 카드 (그린 보더, OHMYHOTEL&CO 추천 + TOP 1/2/3 호텔)
5) 행운의 요소 3분할 (색 / 시간 / 숫자)
6) 클로징 카드 (브랜드-50 배경) + CTA 두 개 (다시 보기 / 처음으로)
```

### 2.6.2 헤드라인 카드

```
OHMYCHI SAJU · 2026년 5월 11일 월요일

김민지 님의 오늘 사주 여행운세

"마음의 나침반이 또렷해지는 하루"

★★★★☆ (4 / 5)
[#불의 기운] [#따뜻한 인연] [#밝은 흐름]

한낮을 향해 가는 따뜻한 불의 사주이에요. 오늘은
작은 결심 하나가 여행의 방향을 바꿔놓을지도 모르겠네요.
```

| 요소 | 사양 |
|---|---|
| 라벨 | `OHMYCHI SAJU · {오늘 날짜 (YYYY년 M월 D일 요일)}` |
| H2 | `{이름} 님의 오늘 사주 여행운세` |
| 헤드라인 | 큰따옴표로 감싼 한 줄 (`text-lg/xl`, brand-700) |
| 별점 | `★★★★★` 5개. 점수만큼 brand-500, 나머지 slate-200 |
| 키워드 칩 | `border-brand-200 bg-white/70` 라운드 풀, `#키워드` 표기 |
| 본문 | `text-ink leading-relaxed` |

### 2.6.3 카테고리 4분할

```
┌─────────┐  ┌─────────┐  ┌─────────┐  ┌─────────┐
│ 여행운   │  │ 재물운   │  │ 인연운   │  │ 건강운   │
│ ★★★★★ │  │ ★★★★☆ │  │ ★★★★☆ │  │ ★★★★★ │
│ (메시지) │  │ (메시지) │  │ (메시지) │  │ (메시지) │
└─────────┘  └─────────┘  └─────────┘  └─────────┘
```

- `grid-cols-2 sm:grid-cols-4`
- 흰 배경 + brand-100 보더 + 작은 카드
- 4개 라벨 고정: `여행운`, `재물운`, `인연운`, `건강운`

### 2.6.5 추천 호텔 카드 (그린 테마)

```
OHMYHOTEL & CO 추천 ●
도쿄에서 묵기 좋은 호텔
오마이호텔 Top 100 (일본) 기준 상위 추천

[TOP 1] ICI HOTEL Tokyo Hatchobori
        Tokyo · 3-26-11 Hachobori, Chuo-ku

[TOP 2] Sotetsu Grand Fresa Tokyo - Bay Ariake
        Tokyo · 3-6-6 Ariake, Koto-ku

[TOP 3] SOTETSU GRAND FRESA TAKADANOBABA
        Tokyo · 1-chome-27-7 Takadanobaba
```

| 요소 | 사양 |
|---|---|
| 카드 보더 | `border-2 border-leaf` (#009505) |
| 라벨 | leaf 컬러, `OHMYHOTEL & CO 추천 ●` |
| 부제 | `오마이호텔 Top 100 ({일본/한국/베트남}) 기준 상위 추천` |
| 호텔 행 | cream 배경 카드, `TOP {i+1}` 배지 (leaf-50) + 호텔명 + 도시·주소 |
| **TOP 순위** | **도시 내 순서 (1, 2, 3)** — 데이터의 국가 전체 `rank` 와 다름 (도시별 정렬 후 인덱스 기반) |
| 호텔 수 | 0~3개 (도시에 매칭 호텔이 없으면 카드 자체 비표시) |

### 2.6.7 클로징 카드

```
사주가 가리킨 도쿄, 오마이호텔과 함께라면 더 편안하게
다녀오실 수 있어요.

[ 다른 사주로 다시 보기 ]  [ 처음으로 ]
```

| 버튼 | 동작 |
|---|---|
| 다른 사주로 다시 보기 | `result` 비우고 `view = input`, **입력값은 유지** (이름·생년월일·시 그대로) |
| 처음으로 | `result` + `input` 모두 초기화 후 `view = input` |

## 2.7 반응형

| 화면 너비 | 동작 |
|---|---|
| sm 이하 (640px ↓) | 시진 grid 3열, 카테고리 grid 2열, 호텔 카드 세로 |
| sm 이상 (640px ↑) | 시진 grid 4열, 카테고리 grid 4열 |

부스 디바이스가 태블릿/노트북 기준이라 sm 이상이 메인 타깃.

## 2.8 컬러 시스템 요약

| 토큰 | 값 | 용도 |
|---|---|---|
| `brand-50/100/200` | `#fff5ed` / `#ffe3cf` / `#ffc499` | 카드 배경, 보더, 칩 |

## 2.9 상태 전이 (요약)

| from \ event | submit | api success | api error | "다시 보기" | "처음으로" |
|---|---|---|---|---|---|
| `input` | → `loading` | — | — | — | — |
| `loading` | — | → `result` | → `input` (error 표시) | — | — |
| `result` | — | — | — | → `input` (값 유지) | → `input` (값 초기화) |
